## Bivariate Analysis

### - order_value vs order_status

```
delivered orders have higher avg order value (~ 160)
canceled orders have lower avg order value (~ 120)
```

### - review_score vs is_delayed

```
on-time orders: avg review 4.3
delayed orders: avg review 2.6
significant difference confirmed by t-test (p ≈ 0)
```

### - payment_type vs order_status

```
credit_card: most common (~75%)
boleto: ~20%
chi-square test shows association between payment type and order status
```

### - category vs order_value

```
bed_bath_table: highest total revenue
health_beauty: second highest

```

### - repeat_customer vs order_value

```
repeat customers spend more per order on average
new customers: avg ~ 150
repeat customers: avg ~ 200
```
